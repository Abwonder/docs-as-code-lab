## What this repository demonstrates

- Docusaurus configuration, Markdown/MDX authoring and explicit navigation.
- A tutorial tied to a runnable, tested Node API example.
- Reference material that documents validation, retry behavior and failure modes.
- Reproducible dependency installation, production builds and generated-link checks.
- A GitHub Actions validation and Pages deployment workflow with scoped permissions.
- Deployment, diagnosis and rollback procedures a reader can practise.

The repository commit history and Actions logs are the evidence for what actually
ran. The README records the implementation process and validation status.

## Provenance

Created in October 2026 as a new, AI-assisted portfolio project. Codex helped
design, write and validate the initial implementation. The owner should inspect
the source, run the release drill and be able to explain the decisions before
presenting independent proficiency in an interview.

This project is not previous employment, a customer deployment, a Camunda
integration or proof of years of production experience. It does not include Java,
Kubernetes or Helm workloads. Documentation that mentions a technology is not the
same as hands-on operational experience with that technology.
