**Signal Harbor is a fictional incident intake service.** Its local API is real,
small enough to inspect, and tested against the behavior documented here. The
documentation site is built with Docusaurus and deployed through GitHub Actions.

## A small, observable delivery loop

<p className="lab-flow">Markdown / MDX → review → API tests → static build → route checks → Pages</p>

This project separates a **tutorial**, task-focused **how-to guides**, an **API
reference**, and explanations of **design decisions**. Start with the tutorial;
use the reference when you need an exact answer.
